# The Capon - WordPress Theme

Тема WordPress для каталога моделей/товаров с системой авторизации, личным кабинетом, управлением заказами и интеграцией с Яндекс.Картами.

## Требования

- WordPress 4.5+
- PHP 5.6+ (рекомендуется 7.4+)
- Плагин **Advanced Custom Fields (ACF)** - обязателен

## Установка

1. Загрузите тему в `/wp-content/themes/the-capon/`
2. Активируйте тему в админ-панели WordPress
3. Установите и активируйте плагин ACF
4. Создайте необходимые страницы и назначьте им шаблоны (см. раздел "Страницы")

## Разработанный функционал

### 1. Система авторизации и регистрации

- **Регистрация** с модерацией администратором
- **Вход в систему** с защитой от брутфорс-атак
- **Восстановление пароля** через email
- **Rate limiting** - ограничение попыток входа/регистрации
- **Логирование** подозрительной активности
- **Блокировка аккаунта** после множественных неудачных попыток

**Файлы:**
- `inc/auth.php` - обработка авторизации
- `js/auth-*.js` - фронтенд логика
- `page-login.php`, `page-register.php`, `page-password-reset.php` - шаблоны страниц

### 2. Личный кабинет пользователя

**Вкладки:**
- **Избранное** - управление списком товаров, создание заказа из избранного
- **Заказы** - просмотр истории заказов с деталями
- **Магазины** - управление магазинами пользователя (для отображения на карте)
- **Настройки** - редактирование профиля пользователя

**Файлы:**
- `inc/user-account.php` - AJAX обработчики
- `js/user-account.js` - фронтенд логика
- `page-lk.php` - шаблон личного кабинета

### 3. Детальные страницы товаров

- **Слайдер изображений** с навигацией
- **Видео** с возможностью фона или проигрывателя
- **Галерея** внутри слайдов
- **Кнопка "Сделать заказ"** - добавление в избранное (только для авторизованных)
- **Статус наличия** товара
- **Параметры товара** из ACF полей

**Файлы:**
- `single.php` - шаблон детальной страницы
- `js/single-slider.js`, `js/single-video.js`, `js/single-model.js` - логика слайдера и видео
- `inc/acf-fields-single.php` - ACF поля

### 4. Страница "Где купить"

- **Интерактивная карта Яндекс.Карт** с маркерами магазинов
- **Список магазинов** с контактами
- **Взаимодействие** - клик по магазину центрирует карту на маркере
- **Данные магазинов** берутся из профилей пользователей

**Файлы:**
- `page-where-buy.php` - шаблон страницы
- `js/stores-map.js` - инициализация карты
- Управление магазинами в личном кабинете (вкладка "Магазины")

### 5. Админ-панель модерации

**Раздел "Модерация":**
- Просмотр всех пользователей
- Редактирование профилей пользователей
- Управление заказами пользователей
- Управление магазинами пользователей
- Изменение статуса аккаунта (pending/approved)
- Удаление пользователей

**Раздел "Регистрация":**
- Просмотр заявок на регистрацию
- Одобрение/отклонение пользователей

**Файлы:**
- `inc/admin-users.php` - админ-панель и AJAX обработчики

### 6. Дополнительный функционал

- **Live Search** - поиск товаров с автодополнением
- **Система уведомлений** - единая система для всех AJAX операций
- **Хлебные крошки** - навигация по сайту
- **Страница "О компании"** - с возможностью видео/фона

## Необходимые страницы

Создайте следующие страницы и назначьте им шаблоны:

| Страница | Шаблон |
|----------|--------|
| Личный кабинет | `page-lk.php` |
| Вход | `page-login.php` |
| Регистрация | `page-register.php` |
| Восстановление пароля | `page-password-reset.php` |
| О компании | `page-about.php` |
| Контакты | `page-contacts.php` |
| Где купить | `page-where-buy.php` |

## Структура проекта

```
the-capon/
├── inc/
│   ├── auth.php              # Авторизация и регистрация
│   ├── user-account.php      # Личный кабинет (AJAX)
│   ├── admin-users.php       # Админ-панель модерации
│   ├── acf-fields-*.php      # Определения ACF полей
│   └── ...
├── js/
│   ├── user-account.js       # ЛК - фронтенд
│   ├── auth-*.js             # Авторизация - фронтенд
│   ├── single-*.js           # Детальная страница
│   ├── stores-map.js         # Яндекс карта
│   └── ...
├── page-*.php                # Шаблоны страниц
├── single.php                # Детальная страница товара
└── functions.php             # Основные функции темы
```

## Безопасность

- Проверка nonce для всех AJAX запросов
- Санитизация всех пользовательских данных
- Rate limiting для защиты от брутфорс-атак
- Проверка прав доступа (`current_user_can`, `is_user_logged_in`)
- Логирование подозрительных событий
